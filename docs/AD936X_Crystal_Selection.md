# AD936X 参考时钟/晶振选型要点

> 整理日期：2026-08-12。依据：AD9361 数据手册 REFERENCE CLOCK 表、ADI 官方
> FMCOMMS2 Tuning 文档、FMCOMMS2 硬件页及 ADI EngineerZone 官方答复，均已实测核验。
> 适用：AD9361 / AD9363 / AD9364（PlutoSDR 为 AD9363，规格族一致，以各自数据手册为准）。

## 1. 参考时钟在 AD936X 中的作用

参考时钟（REF_CLK，接 XTALP/XTALN 引脚）同时驱动两路合成器：

- **射频 PLL**：产生 RX/TX 本振（LO），参考时钟误差按 LO/REF 倍频数等比放大；
- **基带 PLL**：产生 ADC/DAC 采样时钟，误差会让采样率同样偏移相同的 ppm。

因此晶振选型核心指标：频率范围、精度（初始+温漂+老化）、负载电容、激励/驱动电平、
相位噪声（抖动）。

## 2. 数据手册硬性指标（REFERENCE CLOCK 表）

| 参数 | 规格 | 说明 |
|---|---|---|
| 晶振模式（接 XTALP/XTALN） | **19–50 MHz** | 必须 **AT 切、基频**、**负载电容 CL = 10 pF**（AD9361 内部呈现 10 pF，布局寄生电容会叠加） |
| 外部振荡器模式（XTALN 单端输入） | **10–80 MHz** | 幅度 **0.8–1.3 Vp-p，AC 耦合**；幅度越大相噪越好 |
| 频率可校准范围 | **±60 ppm** | 芯片内置 DCXO（数控晶振）粗调+细调，最差分辨率 0.0125 ppm（粗调字=0 时） |

补充要点：

- 数据手册 EVM 指标分别用 19.2 MHz 与 40 MHz 参考时钟测得，两者均可用；
- 40 MHz 参考时钟在芯片内部**倍频到 80 MHz** 给射频合成器使用；
- 外部振荡器模式建议参考频率**尽量靠近 80 MHz**：PLL 倍频数 N 越小，相位噪声恶化
  越小（相噪按 20·log₁₀(N) 恶化）。

## 3. ADI 官方评估板晶振选型实例（可直接参照）

FMCOMMS2/3/4 使用 **Epson 定制 40 MHz 晶振**（TSX-3225 低抖动版）：

| 指标 | 数值 |
|---|---|
| 频率 | 40.000 MHz |
| 初始频率容差 | **±10.0 ppm** |
| 温度稳定度 | **±15.0 ppm（max）** |
| 老化 | **±2.0 ppm** |
| RMS 综合（含老化） | **±18.1 ppm** |
| 负载电容 | 10 pF，AT 切基频 |
| 订货号 | Epson **OUTD-2B-0166** 或 **X1E000021036701** |

官方明确警告：通用货号 "TSX-3225 40.0000MHZ" **不满足 AD9361 数据手册指标**，必须用
上述定制件。ADI 说明该选型是"牺牲绝对精度换低成本"，FMCOMMS2 不适合基站级（BTS）
需要绝对频率的应用。

误差传导量化（官方文档）：±18.1 ppm 在 2.4 GHz 本振产生 **±43.2 kHz** 频偏，
同时 30.72 MSPS 采样率按同 ppm 偏移。

## 4. 采购指标清单（自研板必写）

1. **频率**：40 MHz 最通用（亦可 19.2/26/30.72/38.4/52/61.44/76.8/80 MHz）；
   晶振模式限 19–50 MHz，外部振荡器模式可 10–80 MHz；
2. **切型**：AT 切、基频（禁止泛音/非 AT）；
3. **负载电容 CL = 10 pF**（±0.5 pF 内）；
4. **精度预算**：初始容差 + 温漂 + 老化，总偏差必须落在 DCXO ±60 ppm 可调范围内；
   系统指标允许时留更多余量（通信类常要求总 ≤±5 ppm，GPS 要求更高，见第 5 节）；
5. **ESR / 激励功率**：符合 AD9361 内部振荡电路要求，参照评估板同款器件；
6. **相位噪声/抖动**：官方原话"低抖动比绝对精度更重要"，相噪直接决定 EVM 与跟踪性能；
7. **温度范围**：-40~+85°C 工业级起步（温补需 TCXO）；
8. **封装/寄生**：靠近 XTALP/XTALN 布局，走线短，匹配电容按 CL 计算，远离 RF 与高速数字区。

## 5. 对 GPS 项目（L1 1575.42 MHz）的量化影响

| 晶振精度 | L1 频偏 | 影响 |
|---|---|---|
| ±25 ppm（Pluto 内置规格） | **±39.4 kHz** | 超出捕获搜索 ±10 kHz，真实卫星会漏捕 |
| ±18.1 ppm（FMCOMMS2 实例） | ±28.5 kHz | 同样超出，需扩搜索窗或校准 |
| ±2.5 ppm（普通 TCXO） | ±3.9 kHz | 落在搜索窗内，可直接捕获 |
| ±0.5 ppm（国产 P201Mini 方案） | ±0.8 kHz | 余量充足，跟踪稳定 |

结论：做 Z7020+AD9361 GPS 接收机硬件，建议直接选 **±0.5~1 ppm 的 40 MHz TCXO**，
或预留**外部 10 MHz 参考输入**（参考 USRP B200：10 MHz → ×4 PLL → 40 MHz），
避免靠软件扩搜索窗兜底。

> **落实状态（2026-08-17，用户确认）**：本项目 7020-SDR 新板已采用 **±0.5 ppm TCXO**，
> L1 频偏约 ±0.8 kHz，无需扩搜索窗；真实卫星前仅需一次实测校准。

工程提醒：

- **DCXO 校准只对晶振模式有效**：外部 TCXO 直驱 XTALN 时 ±60 ppm 调谐不可用，
  官方做法是实测振荡器实际频率后回填给驱动（IIO 有频率校正接口）；
- **频率误差逐板不同**：一块板的校准设置不能复制到另一块板，换晶振批次后必须重新校准。
