# M3 跟踪模块验证报告（DLL + PLL）

> **日期**：2026-08-07
> **结论**：✅ **PASS**（离线 Synthetic + TX 合成信号硬件闭环双模式）
> **产物**：`matlab/tracking/tracking.m`、`matlab/tracking/verifyGnssTracking.m`

---

## 1. 目标与验收标准

按交接文档 §9，M3 跟踪模块：

- 输入：`acquisition.m` 输出的 `codePhase`（采样点）与 `dopplerHz`
- 每通道：DLL（码环）+ PLL（载波环），1 ms 相干积分，输出 C/N0
- 复用：`gnssBitEdgeDetect`（位同步）、`generateGnssTxBuffer`（闭环发射源）
- 验收：**环路锁定 + C/N0 稳定 + 位同步成功**（本报告另加子帧端到端对比）

## 2. 实现架构（tracking.m）

```text
data (复基带 IQ) + acq (codePhase/dopplerHz)
   │
   ▼ 逐 1 ms 块（IntegrationMs 可调 1~10 ms 相干积分）
   ├─ 本地载波混频（相位连续，exp(-j(2πft+φ))）
   ├─ E/P/L 三路本地码相关（间距默认 0.5 chip，码相位可为分数）
   │
   ▼ 鉴别器
   ├─ PLL：Costas atan(Q_P/I_P)（对 180° 电文翻转不敏感）
   ├─ DLL：(E-L)/(E+L)（非相干超前减滞后包络）
   │
   ▼ 二阶环路滤波器（位置式 PI：f = f0 + Kp·e + Ki·Σe）
   ├─ PLL BW 18 Hz / DLL BW 2 Hz（ζ=0.7071）
   │
   ▼ 输出
   ├─ codePhase / carrierFreq / carrierPhase（每 ms）
   ├─ C/N0（窄带/宽带功率比，20 ms 窗口**按位同步对齐**）
   ├─ 位同步 + 解调比特（双极性参考匹配）
   └─ lock 判定（C/N0 中值 + PLL 残差 + 码相位稳定性）
```

## 3. 验证方法

```matlab
% 离线（无硬件）：8 s 合成信号，注入 +1200 Hz 多普勒、码相位 777、C/N0=45
verifyGnssTracking('Synthetic', true)

% 硬件闭环（TX 合成 GPS → RX step() 连续流）：天线场景默认 TX -65 dB
verifyGnssTracking
```

硬件链路：`generateGnssTxBuffer`（1 个 300 位子帧，6 s）→ Pluto `transmitRepeat`
持续发射 → RX `step()` 连续流采集 12.5 s → 捕获 → 跟踪 → 位同步 → 子帧解码对比。

采集 12.5 s 的原因：跟踪段必须含至少 1 个完整 300 位子帧（任意位对齐下
需 ≥ 600 位 ≈ 12 s），子帧解码才能做奇偶校验。

## 5. 关键技术发现与踩坑（新增，详见 HANDOFF §6）

1. **二阶环路滤波器必须用位置式 PI**（`f = f0 + Kp·e + Ki·Σe`），不能用增量式
   `f += Kp·e + ...`：增量式会把比例项也积分成双积分器，噪声下频率随机游走、
   频偏下极限环不收敛（实测发散到 −55 kHz）。位置式从 40 Hz 离格频偏可在
   ~1 s 内牵入。
2. **Costas 鉴别器是模 π 的**（atan(Q_P/I_P)）：牵入范围只有环路带宽量级，
   大频偏必须靠 FLL 或高精度捕获初值；本实现初值来自捕获（DopplerStep=100
   时误差 ≤50 Hz），位置式环路可可靠牵入。动态多普勒场景建议后续加 FLL 辅助。
3. **C/N0 的 20 ms 窗口必须按位同步对齐**：窗口横跨比特翻转时窄带功率被抵消，
   C/N0 被低估 ~25 dB（实测 35.9 → 11.2 dB-Hz，比特仍 0 误码）。先位同步、
   再按 `(bitOffset + skipMs) mod 20` 对齐窗口计算 C/N0。
4. **跟踪段长度**：端到端子帧解码需 ≥ 600 位跟踪比特（12 s 采集），否则
   300 位子帧窗口可能被截断（385 位时子帧起点落在 286 位即失败）。
5. **参考比特匹配必须测双极性**：BPSK 180° 极性模糊下 `bits==ref` 只有 ~63%，
   测 `bits==1-ref` 后 100%；真实接收机用前导码+奇偶校验消除极性
   （`gnssSubframeDecode` 已内置）。
6. **1 ms 分数码相位不改变位同步偏移**：码延迟 0.31 ms 时，1 ms 相关流中的
   比特边缘仍落在块边界（多数比特立即胜出），能量法 + 翻转直方图法均可靠。

## 6. 遗留与下一步

- 跟踪目前为**整段数据处理**（采集 → 离线跟踪）；M3 标题中的"实时"下一步
  可改为 `step()` 分块在线处理（双缓冲后台采集 + 主线程逐块跟踪）。
- 多通道跟踪已支持（PRNList 数组），硬件仅单星验证，后续真实卫星多通道测试。
- 弱信号（C/N0<35）需调窄 PLL 带宽（如 10 Hz）并验证。
- M4：星历子帧 1/2/3 字段解析 → 伪距 → 最小二乘定位 → uifigure 实时 GUI。
