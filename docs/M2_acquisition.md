# M2 捕获模块：FFT 并行码相位搜索

> 完成日期：2026-08-07（离线调通，合成信号验证）
> 状态：合成信号 6/6 PASS；真实卫星待 bias-T 到货后验证

## 目标与验收

对复基带 GPS L1 C/A 信号执行二维搜索（32 颗 PRN × 多普勒 ±10 kHz），
输出每颗卫星的**码相位**、**多普勒频移**和**检测指标（峰值/噪声均值）**，
为 M3 跟踪模块提供初始值。

验收标准：

1. 合成信号（已知码相位/多普勒/C/N0）能正确捕获，码相位误差 ≤2 采样点，
   多普勒误差 ≤ 搜索步进
2. 纯噪声下无虚警（门限 6，8 组随机种子实测噪声最大指标 3.4~3.6）
3. bias-T 到货接有源天线后，能捕获 ≥4 颗真实卫星（待硬件验证）

## 算法说明

对每颗 PRN：

1. 用 `gnssCACode(prn, 'GPS')` 生成 C/A 码（1023 chips），按采样率重采样
2. 对每个多普勒候选频率，用 `exp(-j*2*pi*(IF+fd)*t)` 混频去载波
3. 与码副本做 **FFT 圆周相关**（FFT 长度 = 块长）
4. 多块非相干累加 `|corr|²`，取峰值位置为码相位，峰值/噪声均值（剔除峰 ±2 点）
   为检测指标
5. 指标 ≥ 门限判为捕获

## 关键实现决策（踩坑记录）

### 1. FFT 相关必须是圆周相关

初始实现用 `nfft = 2^nextpow2(块长)` 零填充做相关，得到的是**线性相关**：
码相位接近码周期末尾时（如 2495/2500）无法回绕对齐，峰值位置和幅度都错。
码相位搜索要求**码周期内回绕对齐**，因此 FFT 长度必须等于块长
（与 SoftGNSS 一致）。

### 2. 码相位语义

码相位定义为**从块起点到下一个码周期起点的延迟（采样点）**，
输出为 1-based 索引，可直接作为 M3 跟踪的初始码相位。
合成信号生成器采用相同语义（`(n - CodePhase)` 采样码片）。

### 3. 多普勒格点量化

500 Hz 步进下多普勒估计误差 ±250 Hz（格点量化）。
弱信号（C/N0 < ~38 dB-Hz）在 1 ms 相干积分下检测指标低于门限，
应使用 `IntegrationMs > 1` 相干积分并相应减小 `DopplerStep`
（如 5 ms 相干配 100 Hz 步进，实测 C/N0=35 dB-Hz 可靠捕获）。

### 4. 检测门限标定

门限默认 6（峰值/噪声均值）。8 组随机种子的纯噪声全 32 PRN 扫描，
最大指标 3.39~3.62，零虚警，余量约 1.7 倍。

## 回环验证（TX 合成 GPS → RX 捕获）

在真实卫星不可用的条件下，用 Pluto TX 发射合成 GPS L1 C/A 码，RX 接收后捕获，
验证全射频链路（2026-08-07，回环线 TX→RX 直连，2.5 MSPS）：

| 项 | 结果 |
|---|---|
| 目标星 | PRN5 命中，metric 69.0，多普勒 **+0.0 Hz**（共时钟），码相位任意 |
| 其余 PRN | 3.4 ~ 4.1（噪声级，无虚警） |
| 领先度 | 17.8×（判定标准 ≥3×） |
| 结论 | **PASS** |

关键发现（踩坑记录）：

1. **Pluto TX `Gain` 属性范围 0 ~ -89.75 dB，0 = 最大输出**。
   最初沿用 M1 的 `Gain=0` 并以"最低功率"注释，实际是最大功率，
   回环线直连导致 RX 削波 79%。校准后确认：负值才是衰减。
2. **强信号 C/A 码互相关**：C/N0 ≈ 66+ dB-Hz 时，32 颗 PRN 全部越过门限 6，
   这是强信号互相关伪峰（真实 GPS 信号互相关比峰值低 ~24 dB，低于噪声底）。
   把功率压到真实 GPS 量级（TX Gain=-89.75 dB + 幅度 0.034，C/N0≈45 dB-Hz）
   后只剩目标星。判定标准采用"目标指标 ≥ 3× 次高"以兼容强信号场景。
3. TX 缓冲必须为整数个 C/A 码周期（20 ms = 50000 采样），保证 `transmitRepeat`
   相位连续（沿用 M1 结论）；TX/RX 采样率一致（2.5 MSPS）。

复现：

```matlab
cd('GNSS-SDR-IN-MATLAB/matlab/acquisition')
verifyGnssLoopback('TxGain', -89.75, 'TxAmplitude', 0.034)   % 需 TX→RX 回环线
```
