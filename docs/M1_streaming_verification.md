# M1 验证方案：PlutoSDR 连续采集链路完整性

## 目标

验证 PlutoSDR 以 **4 MSPS**（可调）为目标采样率，能**连续、无丢帧**地输出 IQ 数据，
为后续实时 GPS 捕获/跟踪（M2–M4）提供可靠的数据通道。M1 不依赖 GPS 卫星信号，
用 **TX→RX 回环测试音**做确定性校验。

## 环境准备

- PlutoSDR 通过 USB 连接（识别出 "PlutoSDR Serial Console (COMx)" 与 RNDIS 网卡）
- **TX→RX 回环线**（SMA 短线，TX 口直连 RX 口）——必接，用于测试音
- bias-T / 有源天线**不需要**（M1 只验数据链路）

## 关键结论（2026-08-06 实测）

1. **`capture(rx, N)` 循环不可用于实时流**：每次调用重新同步，帧间数据不连续
   （实测每帧 ~124 ms、逐帧相位跳变）；`capture` 只适合一次性大块采集。
2. **`step(rx)` 是连续流接口**：帧内容首尾相接，相位连续。
3. **测试音必须相位连续**：`transmitRepeat` 缓冲须含整数个信号周期
   （3 ms × 97.333 kHz = 292 整周期）；否则发送端自身跳相，会误判接收端丢帧。
4. **内核缓冲 `kernelBuffersCount=32`** 吸收偶发调度延迟。
5. 实测（4 MSPS，10 ms 帧，20 s）：稳态帧间隔 **9.77 ms**（快于实时），
   **相位跳变 0 次**，有效吞吐 **3.87 MSPS**；首次 `step()` 有 ~0.7 s
   一次性初始化延迟。

## 验证方法与指标

### A. GPS L1 前端健康（链路 sanity）

无测试音、AGC 模式抓 10 帧：

| 指标 | 阈值 | 说明 |
|---|---|---|
| RMS 幅度 | 1e-4 ~ 0.7 | 不静默、不满幅 |
| 削波比例 (|x|>0.999) | < 5% | AGC 无信号源时轻微削波属正常 |
| DC 偏移 | < 0.3 | |

### B. step() 连续流采集（核心）

`step(rx)` 循环采集 N 秒（默认 15 s，帧 10 ms，`kernelBuffersCount=32`）：

| 指标 | 判定 |
|---|---|
| 总样本数 | 严格等于 fs × 时长 |
| 稳态帧间隔（跳过前 2 帧）均值 | ≤ 1.2 × 帧周期（≤12 ms） |
| 帧间隔 p95 | ≤ 1.5 × 帧周期 |
| 单帧处理耗时最大值 | < 500 ms（缓冲可吸收） |
| 有效吞吐率 | ≥ 0.9 × fs |

### C. 回环测试音相位连续性（丢帧判定关键）

TX 发射**相位连续**测试音（97.333 kHz，3 ms 缓冲整数周期），RX 逐帧解算相位。

**原理**：帧长 10 ms × 97.333 kHz = 973.33 周期（**非整数**），相邻帧相位步进
≈ 0.33×2π ≈ 2.09 rad，为已知固定值；丢帧会使步进突变——**相位跳变即丢帧**。

| 指标 | 判定 |
|---|---|
| 测试音频率检测 | 与 97.333 kHz 误差 < 1 kHz |
| 测试音 SNR | > 10 dB |
| 帧间相位跳变次数 | = 0 |
| 相位步进最大偏差 | < 0.5 rad |

### D. 大块 capture 对照（信息项，不参与 PASS）

一次性 `capture(rx, 2 s)` 检查样本数与相位线性度。实测 capture 有效速率约
1.5 MSPS，**不能**作为实时流方案。

## 运行步骤

```matlab
cd('GNSS-SDR-IN-MATLAB/matlab/frontend')
verifyPlutoStream                            % 默认 4 MSPS, 15 s
verifyPlutoStream('DurationSec', 30)         % 加长验证
verifyPlutoStream('Fs', 2.5e6, 'DurationSec', 10)  % 低采样率对照
```

输出：命令窗口逐项 PASS/FAIL 汇总 + `data/verify_<时间戳>.mat/.png`。

## 判定标准

**PASS** = A/B/C 全部通过（D 仅作对照，不判 FAIL）。

## 失败排查指引

| 现象 | 排查 |
|---|---|
| 找不到设备 | USB 线/口、驱动；设备管理器应有 "PlutoSDR Serial Console" |
| 测试音 SNR 低 | 确认回环线接 TX 与 RX 口；调低 rxGain 或调大 toneAmp |
| 削波 > 5% | 降低 rxGain 或 toneAmp |
| 相位跳变 > 0 | 确认测试音缓冲为整数周期（toneFreq×0.003 为整数）；检查 USB 供电 |
| 稳态帧间隔超预算 | 关闭其他 MATLAB 进程/杀毒；改用 int16 输出数据类型 |

## 与后续里程碑的关系

- M1 PASS 后，**M3 实时化直接采用 `step()` 连续流 + 双缓冲架构**
- M1 的"稳态帧间隔 ≤ 1.2 帧周期"预算约束 M3 每帧处理算法开销
- `capture()` 仅用于离线大块采集（M2 调试数据来源）
