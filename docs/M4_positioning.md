## 1. 方法与链路

以真实 GPS 星座几何为基准做**定量验证**：

```text

   ▼

   ▼

   ▼
```

## 2. 关键发现：亚毫秒比特边界解析（伪距精度的核心）

子帧起点 = 比特边界 = **码相位零点**，位于毫秒网格的**分数位置**。
仅用整数毫秒比特同步锚定子帧会产生每星 ±1 ms（300 km）的伪距歧义
（实测初版位置误差 1776 km、残差 49 km）。

解法（`gnssPseudorange.m`）：

1. 20 个整数比特相位候选求 20 ms 累加能量曲线，**抛物线插值**得亚毫秒
   比特相位 b_true；
2. 子帧起点分数毫秒 P = skipMs + b_true + (syncIndex-1)×20；
3. 码相位零点采样 e_sf = **floor(P)×msLen + codePhase(floor(P)+1)**；
4. ρ = c×(e_sf/fs − T_sf)，T_sf = (TOW−1)×6 s。

修复后 6 星伪距 vs 注入延迟最大偏差 **6.5 m**（注入量化 120 m/采样点
被码相位亚采样跟踪吸收）。

## 4. 其他要点

- **统一锚定子帧 1**：不同子帧起点差 6-12 s，卫星位移 ~50 km，会造成
  几何不一致；须统一在子帧 1（TOW 基准一致）锚定伪距与卫星位置
- **28 s 采集保证完整子帧 1**：有效比特 ≥1199 才保证任意对齐下含完整
  子帧 1（24 s 时最差对齐被截断，实测 PRN 11 失败）
- **多星间 18 s 重复周期歧义是公共的**（各星缓冲同相位），被钟差吸收，
  不影响位置
- 选星按仰角取前 6（保证几何分布），GDOP 7.7 在门限内

### 关键排障（多星硬件捕获码相位跑偏）

初版（5 ms 相干捕获 + TX −65 dB）6 星全检出但跟踪全失锁：捕获码相位对
部分卫星偏差 500~1000 采样（DLL 牵引范围仅 ~1 chip，必失锁）。排障过程：

1. 单星硬件基线 PASS（CN0 39.1）→ 排除 RF 环境
2. 4 星同样失败 → 排除星数干扰
3. 捕获改 **1 ms 相干积分** → 6 星码相位全部精确（公共偏移 δ=818 一致）：
   **根因是 5 ms 圆周相关对周期码有 ±1 ms 多周期歧义**，多星/噪声下
   部分卫星锁到错误周期
4. TX 增益 −65 → **−60 dB**（+5 dB）→ 6/6 检出且 CN0 ~43

硬件模式默认参数已固化：`AcqIntegrationMs=1`、`TxGain=-60`、
`CaptureSec=12.5`（仅子帧 1，星历用 RINEX 已知数据）。
