## 2. 回环线档位标定（2026-08-17）

### 2.1 方法

- 射频连接：RX1A ↔ TX1A SMA 短接（回环）
- TX 固定档位：PRN 5 合成 C/A 码，增益 **−89.75 dB**，幅度 **0.034**，2.5 MSPS，中心 1575.42 MHz
- RX：手动增益 10→60 dB 逐点扫，每点跑完整 `verifyGnssTracking('Synthetic', false, ...)`（12.5 s 采集 + 捕获 + DLL/PLL 跟踪 + 子帧解码）
- 附加检查：RX 70 dB 下捕获 3 s 数据做削波检查
- 度量指标：捕获指标（metric）、跟踪 CN0（20 ms 窗口按位同步对齐）、频率误差、码相位 std、子帧解码数

### 2.2 结果

| RX 增益 | 捕获指标 | CN0 (dB-Hz) | 频率误差 | 码相位 std | 子帧解码 | 判定 |
|---|---|---|---|---|---|---|
| 10 dB | 16.3 | 33.1 | −0.24 Hz | 0.029 采样 | 1/1 | FAIL（CN0 < 35） |
| 20 dB | 50.5 | 40.6 | +0.03 Hz | 0.026 | 1/1 | PASS |
| 30 dB | 264.6 | **45.7** | +0.01 Hz | 0.007 | 1/1 | PASS |
| 40 dB | 318.3 | **45.7** | +0.02 Hz | 0.007 | 1/1 | PASS |
| 50 dB | 365.4 | **45.7** | +0.01 Hz | 0.006 | 1/1 | PASS |
| 60 dB | 326.6 | 44.7 | +0.02 Hz | 0.007 | 1/1 | PASS |
| 70 dB（削波检查） | — | — | — | — | — | RMS 0.036 / 峰值 0.104 / 削波 0.00% |

### 2.3 结论

1. **CN0 平台区 = RX 30~50 dB，平台值 45.7 dB-Hz**——该 TX 档位回环下的真实信噪比上限；60 dB 略有回落（44.7）。
2. **推荐回环线档位：TX −89.75 dB / 幅度 0.034 / RX 40 dB**（CN0 45.7、误码 0、子帧 1/1、余量充足）。
3. **低增益段为量化噪声受限**：10 dB → CN0 33.1、20 dB → 40.6，明显低于平台值。这是"指标随增益暴涨"（16.3→318）的原因。
4. **无削波风险**：RX 70 dB 时峰值 0.104，离满幅约 20 dB 余量；该 TX 档位下可放心用高 RX 增益。
5. 捕获阶段（verifyGnssLoopback）交叉验证：RX 10 dB → metric 8.6（未过 3× 领先度），RX 40 dB → metric 358.1 / 领先度 50.9（PASS）。

## 6. 有源天线 Bias-T 增益测试（2026-08-17）

### 6.1 目的与接线（踩坑后修正版）

- 目的：量化有源 GPS 天线（标称 1555~1580 MHz）在"直连 RX1（LNA 不供电）"与"Bias-T 供电（LNA 工作）"两种状态下的接收增益区别。
- 正确接线（本次有效数据）：
  - TX1A → 拉杆天线（1/4 波长）
  - RX1A ← Bias-T RF 口；Bias-T RF+DC 口 ← 有源天线；Bias-T DC 口 ← 电源（实测 RF+DC 口 4.9 V）
  - 直连状态：有源天线 RF 输出直接 → RX1A（无 DC）
- ⚠️ **重大踩坑**：初次测试 TX/RX 接反（拉杆在 RX1、有源天线在 TX1），导致"有源天线在发射端、LNA 不在接收链路"，数据全部无效；且 RX1 口存在来自 TX1 的强泄漏（拔掉天线仍有 −29~−33 dBFS），必须做泄漏对照才能下结论。

### 6.2 测试条件

- TX：CW 单音（基带 +100 kHz 偏移），TX 增益 **−20 dB**，幅度 0.1，2.5 MSPS，中心 1575.42 MHz 档
- RX：手动增益 **40 dB**（两种情况固定一致，AGC 关闭），每频点 0.5 s 捕获 FFT 测峰
- 频点：1555/1560/1565/1570/1575/1580 MHz；TX-RX 距离约 1.2 m，切换接线时天线位置朝向不动
- 全景频谱：20 MSPS × 5 段（中心 1500/1520/1540/1560/1580 MHz）拼接 1500~1600 MHz

### 6.3 实测数据（dBFS，均为有效数据）

|---|---|---|---|---|---|
| 1555 | −32.0 | −31.9 | −19.5 | +12.5 | +12.5 |
| 1560 | −32.1 | −34.4 | −19.9 | +14.6 | +12.2 |

- 噪声底（1575.42 MHz）：Bias-T −62.4 dBFS / 直连 −65.8 dBFS（LNA 供电时高 3.4 dB，佐证 LNA 工作）
- 频率测量：全部频点测得偏移 +100000.0 Hz（0 误差），无削波
- 频谱形状：1500~1600 MHz 呈带通包络；1555~1580 MHz 内 1565~1570 为凹陷区

### 6.4 结论

1. **LNA 有效增益约 7~12 dB（相对泄漏基底均值 ≈ 10 dB）**；"BiasT−直连"差值（均值 9.6 dB）是增益下界——直连电平与泄漏基底相当（±3 dB），说明 LNA 断电时有源天线几乎不输出信号。
2. 带内频率选择性：1565~1570 MHz 增益最低（凹陷约 5 dB），1555/1560/1575 较强。
3. 测试方法要点（论文可复用）：TX/RX 接线核对 → 固定 RX 手动增益 → 泄漏对照（拔天线测基底）→ 差分评估，避免泄漏假象。
4. 真实卫星使用建议：bias-T 供电电压按天线标称（本次 4.9 V 正常工作），天线应放置开阔处；本测试的 LNA 有效增益与带内响应可作为接收链路预算依据。

- 捕获：6/6 注入星全部检出并跟踪；单星 **CN0 = 45.7 dB-Hz**、频率误差 ≤0.05 Hz、609 位/星
